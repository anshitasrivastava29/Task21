 OmniFood - Responsive Food Delivery Website

About This Project
This is a beginner-friendly responsive food delivery landing page.
The project is made using only HTML and CSS.

Sections
1. Header and Hero
2. How It Works
3. Our Cities
4. Customer Testimonials
5. Pricing Plans
6. Footer

Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

How To Run
1. Open this project folder in VS Code.
2. Open index.html.
3. Right-click on index.html.
4. Click Open with Live Server.
5. The website will open in your browser.

You can also double-click index.html and open it directly in a browser.

Responsive Design
The website works on desktop, tablet and mobile screens.
Media queries are used in CSS to change the layout for smaller screens.
