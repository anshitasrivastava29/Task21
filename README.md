OmniFood Responsive Food Delivery Page

About:
This is my responsive food delivery landing page for the TuteDude MERN Stack assignment.
I made the page using HTML and CSS. I also used Font Awesome for the icons.

What is included
The page has these sections:
1. Header and hero section
2. How it works
3. Cities
4. Customer reviews
5. Pricing plans
6. Footer

Technologies
- HTML
- CSS
- Flexbox
- CSS Grid
- Media Queries
- Font Awesome


How to run
1. Download or clone the project.
2. Open the folder in VS Code.
3. Open `index.html`.
4. If Live Server is installed, right-click the file and select **Open with Live Server**.
5. The page will open in the browser.

The project can also be opened by double-clicking `index.html`.
